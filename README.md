## **Project Overview**
This repository serves as a collection of coding challenges and algorithms in Java. These problems are commonly asked in software engineering interviews at entry-level positions (SDE-1). The goal is to improve problem-solving skills, understand core data structures and algorithms, and practice Java programming.

### **Key Features:**
- **Data Structures**: Arrays, Linked Lists, Stacks, Queues, Trees, Graphs
- **Algorithms**: Sorting, Searching, Dynamic Programming, Recursion, Greedy Algorithms
- **Coding Challenges**: Simple programming exercises to reinforce Java basics

### **Explanation of Folders and Files:**

1. **Root Directory:**
   - `DAY1_ATM.java`: ATM simulation for basic transactions (deposit, withdraw, check balance).
   - `DAY1_CALCULATOR.java`: A simple calculator program.
   - `DAY1_MIN_OF_THREE.java`: Finds the minimum of three numbers.
   - `SLIDING WINDOW.docx`: A document explaining the sliding window technique.

2. **src/com/dsa**: Contains various coding exercises and algorithms.
   - **`algo/patterns`**: Java programs for different patterns (e.g., stars, numbers).
   - **`algo/sorting`**: Sorting algorithms like Bubble Sort, Merge Sort, Insertion Sort.
   - **`basics`**: Simple exercises such as basic arithmetic and calculator programs.

3. **src/java/array**: Problems related to arrays.
   - `Reverse_the_array.java`: Reverses the elements in an array.
   - `Min_Max_Array.java`: Finds the minimum and maximum values in an array.

## **Coding Challenges & Algorithms**

### **1. Basic Programming Exercises**
   - **`DAY1_add_numbers.java`**: Adds two numbers.
   - **`DAY1_Calculator.java`**: A basic calculator that performs arithmetic operations (addition, subtraction, multiplication, division).
   - **`DAY1_MIN_OF_THREE.java`**: Finds the minimum value among three numbers.

### **2. Patterns**
   - **Pattern Programs**: Java files for printing various patterns (e.g., stars, numbers). Located under `src/com/dsa/algo/patterns`.

### **3. Sorting Algorithms**
   - Common sorting algorithms such as:
     - **BubbleSort.java**
     - **InsertionSort.java**
     - **MergeSort.java**
     - **SelectionSort.java**
   - These programs implement basic sorting algorithms to help understand their mechanics.

### **4. Array Problems**
   - **`Reverse_the_array.java`**: A program to reverse the elements of an array.
   - **`Min_Max_Array.java`**: A program to find the minimum and maximum elements in an array.
